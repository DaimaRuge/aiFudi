## 一、 项目愿景与品牌叙事 (Project Vision)

* **项目名称**：浮光掠影 (The Ephemeral & The Eternal)
* **商业标语**：**"捕捉浮光碎影，重构数字灵魂。"**
* **愿景升华**：

> **以数字之骨，淬精神之魂；以个体微光，汇文明巨著。**
> 本项目旨在将千百年来属于极少数圣贤豪杰的"立德、立功、立言"之特权，通过普惠的多模态 AI 技术赋予每一个平凡而伟大的生命。通过无感知的"伴生式记录"，系统在个体在世时担任无形的"数字史官"；在个体离世后，演进为具备底层价值观的"数字生命体"，打造跨越时空的"数字家族祠堂"，最终实现**生命可沉淀、精神可对话、文明可传承**。

## 二、 古代生命纪实三大范式之 AI 数据映射 (Ancient Paradigms)

本项目底层数据模型深度融合并映射了中国古代系统的生命纪实文体规范，拒绝流水账，建立起具备文学与哲学高度的模型 Prompt 基座：

| 古典文体范式 | 传统规范内核 | 【浮光掠影】系统数据模型映射 |
|---|---|---|
| **1. 墓志铭范式** (盖棺定论，空间沉淀) | 分为**"志"**（散文，记叙生平世系、名讳籍贯、历任功业、子孙现状）与**"铭"**（韵文，四言或四六骈体，对灵魂特质定性赞颂）。 | **核心元数据与 RAG 人格基座**：锚定家族知识图谱（Knowledge Graph）节点，精炼一生核心品格与归宿，作为数字生命体对话时的底层身份约束（System Prompt Barrier）。 |
| **2. 纪传/列传范式** (以事显人，起承转合) | 拒绝平铺直叙。重点记录少年志向、人生冲突、至暗时刻与重大抉择，通过关键历史切片折射人物性格，篇末附加第三方哲理评述（**太史公曰/论赞**）。 | **因果事件与价值观提取引擎**：Agent 专注于识别数据流中的"生命转折点（Turning Points）"，深度分析用户在危机或高光时刻的决策逻辑，克隆其深层价值观。 |
| **3. 年谱范式** (谱以纪年，绝对时空) | 以年、月、日为绝对坐标。左记年龄年份，右记核心事迹。并引入他人书信、日记及唱和诗文作为旁证互证。 | **多模态无感时空对齐（Timeline）**：将照片 Exif、微信图文、差旅轨迹按绝对时间轴拉平，形成可信的"数字年谱裸数据链"，支持多源数据交叉互证。 |

## 三、 AI + Multi-Agent 系统技术架构设计 (Technical Architecture)

系统依托于基于 **OpenClaw** 框架演进的多 Agent 协同流水线，实现从原始数据到数字生命体的完整流转：

```
[原始输入: 语音/图文/Exif]
 ↓
[太史局 Agent: 时空对齐与去噪]
 ↓
[履历结构化 Agent] ──→ (生成家族知识图谱)
 ↓
[价值观萃取 Agent] ──→ (提炼底层人格标签)
 ↓
[视觉 Stylist Agent] ──→ (渲染生命电影/活化老照片)
 ↓
[Soul Activation Engine] ──→ (注入 Ollama 本地模型，激活数字生命体)
```

### 3.1 核心 Agent 流水线流转规范

1. **多模态无感接入 Agent (Data Ingestor)**
   * **核心职责**：多渠道捕获用户原始数据，包含长辈口述历史语音、社交媒体动态（微信朋友圈、博客）、照片及其内嵌 Exif 时空元数据。

2. **太史局 · 时空对齐 Agent (Temporal Aligner)**
   * **核心职责**：消除格式壁垒。识别噪声（剔除无意义碎碎念），提取绝对时间戳与地理位置，将图像与文本精密绑定，输出标准的"结构化数字谱前/正谱裸数据"。

3. **志与履历结构化 Agent (The Zhi-Extractor)**
   * **核心职责**：提取个体基础元数据。通过命名实体识别（NER）和关系抽取构建"家族血缘与人脉网络知识图谱"；梳理其职业生涯里程碑及地理迁徙轨迹。

4. **以事表德 · 价值观萃取 Agent (The Biographer)**
   * **核心职责**：深度语义理解与情感分析。专门捕捉"危机与冲突事件"，分析用户在面对困境时的情感曲线与最终决策。通过因果推理，提取出如"坚韧"、"包容"、"果断"等人物底层性格标签。

5. **动态行乐图 · 视觉 Stylist Agent (The Visual Stylist)**
   * **核心职责**：多模态生成内核。利用超分辨率算法修复老照片；利用面部表情驱动（如 LivePortrait）与声纹克隆让静态容像"说话"；通过 T2V（文本生成视频）与一致性保持算法，渲染高还原度的生命长河短片。

6. **数字夫子 · 生命体激活 Kernel (Soul Activation Engine)**
   * **核心职责**：将清洗后的结构化文本、知识图谱及克隆价值观输入本地 Local LLM（如基于 Ollama 部署的专属模型）进行 RAG 增强，使其具备原主人的思维逻辑和语言习惯，正式激活数字生命体。

## 四、 核心功能模块需求 (Core Features - MVP 阶段)

### 4.1 模块一：古典三范式数字资产生成

* **【动态数字年谱】**：提供一键式 Timeline 视图。用户滑动年份，左侧呈现"行年三十有五"，右侧展现当年核心事迹、活动轨迹，并支持点击查看当年的原始照片、日记及好友互动记录（模拟古代唱和）。
* **【家族史记列传】**：大模型摒弃平铺直叙，精选 3-5 个最具戏剧张力与人生启迪的"关键切片"（如恢复高考、中年下海、渡过大病），以"以事显人"的叙事笔法撰写传记，并在篇末生成客观深刻的 AI "太史公曰"论赞。
* **【传神四维墓志铭】**：生成生平最终定性报告。包含详尽的世系归宿元数据，以及一段由 AI 自动对仗生成的四言/四六骈体"铭文"，用极具仪式感的传统修辞升华灵魂。

### 4.2 模块二：视觉行乐图复活引擎 (视觉生成需求)

* **老照片容像高清修复与基因逆推**：对低清、破损老照片进行无损重构，补充面部细节。针对无法留下影像的远祖辈，根据文献文字描述（如"高颧骨、凤眼、神态清癯"），结合直系后代的面部微特征，进行基因级图像反向合成，补全家族视觉谱系。
* **时空一致性生命长河电影**：支持一键生成 3-5 分钟的《个体生命轨迹电影》。利用**角色一致性保持算法 (Character Consistency)**，确保主角在童年、青年、老年视频中的骨相、基本神态具备高度连续性。AI 导演自动检索历史数据库，逼真还原时代背景（如 70 年代的工厂、80 年代的绿皮车）。

### 4.3 模块三：终端交互与伴生构建 (Hardware & Terminal)

* **跨时空精神重合触达 (App/Web 端)**：当子孙后辈到达某一特定年龄或面临人生抉择（如 25 岁面临职业转型）时，系统自动推送："30年前的今天，你的祖辈也在同样的境遇下做出了决定，这是他的故事..."，实现精神的血脉觉醒与同频共振。
* **全息家庭光影框 / 智能硬件外设**：针对家庭场景设计的硬件终端。日常通过**环境计算 (Ambient Computing)** 感知家人存在。平时可作为动态山水画或动态长辈容像，当后辈靠近或提问时，能够随时以长辈的克隆声纹、方言口音、语气助词及思维逻辑进行实时互动对话。
