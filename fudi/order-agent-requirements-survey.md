# 订单处理 Agent 需求调研问卷

> **项目**: 华住易购订单自动化 Agent  
> **调研目的**: 梳理现有订单处理全流程，识别自动化机会点，为 Agent 系统设计提供输入  
> **调研日期**: 2026-03-27

> **决策人**: CEO 杜群

## 一、业务背景（已确认）

### 1.1 产品范围
- 酒店客房模块化家具
- 照明系统
- 照明控制系统
- 智能可控系统

### 1.2 技术约束（已确认）
| 系统 | 接口情况 | 备注 |
|------|---------|------|
| 华住易购 | 无 API，纯浏览器 | SaaS 平台，浏览器运行 |
| 内部 ERP | 无 API 接口 | 需要人工录入 |
| 轻流（报价） | 飞书第三方应用 | 在飞书内操作 |
| 产品编号映射 | Excel 查询 | 华住编号 ↔ 内部编号 |
| OCR | GLM 视觉模型 | 识别订单截图/文档 |

### 1.3 技术底座（已确认）
- **Agent 框架**: OpenClaw
- **主力 LLM**: GLM-5-turbo
- **备用 LLM**: Minimax M2.7 / Seed-2.0-pro
- **OCR**: GLM Vision
- **部署环境**: 公司 Mac Mini 本地部署
- **多 Bot**: 支持多个飞书 Bot
- **多主机**: 支持多主机运行
